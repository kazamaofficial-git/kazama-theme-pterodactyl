# 💫 Tentang Kazama Cloud

**Kazama Cloud** adalah theme Pterodactyl modern bergaya dark-glass yang dikembangkan oleh **Kazama Tech**. Theme ini **tidak mengubah seluruh panel**: halaman bawaan Pterodactyl (Console, Files, Databases, dst.) tetap dipakai. Yang diganti hanya bagian yang membuat panel terasa seperti platform hosting sendiri:

- 🔭 **Dashboard realtime**, **Daftar Server**, **Sidebar/Drawer**, dan menu akun baru
- 🔐 **Login & Daftar baru** dengan Google OAuth dan Email + Password
- 🛡️ **Akses Terbatas** untuk admin non-utama (cocok untuk reseller server)
- ⏳ **Masa aktif server** 30 hari dengan auto-suspend dan auto-delete
- 🔔 **Notifikasi** (ikon lonceng) dari admin dan peringatan server mau expired
- 💾 **Panel Backup** (admin) dan **Auto-Backup per server** dengan jadwal **WIB**
- 🌐 **Bahasa Indonesia** (default) dan English, semua waktu tampil dalam WIB

| **Admin → Kazama Cloud** | Panel Backup, Notifikasi, Pengaturan Kazama, Masa Aktif Server |

# 🛡️ Akses Terbatas (Detail)

Berlaku untuk **semua admin kecuali admin ID 1** (super admin). Dijaga di tiga lapis: UI admin, Application API, dan Client API.

<div align="center">

| | Admin ID 1 | Admin lain (Terbatas) |
|---|:---:|:---:|
| Nest, Node, Allocation, Location, Mount, Database Host, Settings, Panel Backup | ✅ | ❌ |
| Melihat **semua** User & Server | ✅ | ❌ (hanya yang ia buat) |
| Membuat User & Server | ✅ | ✅ |
| Mengubah konfigurasi server (nama, deskripsi, RAM, Disk, CPU, dst.) | ✅ | ✅ (milik sendiri) |
| Suspend / Unsuspend server | ✅ | ✅ (milik sendiri) |
| Menghapus server / user | ✅ | ❌ |
| Server buatan admin lain | ✅ | ❌ (404) |
| Membuat user sebagai admin | ✅ | ❌ (otomatis non-admin) |

</div>

> Setiap server yang dibuat otomatis tercatat pembuatnya (`kazama_created_by`). Pemilik server oleh admin terbatas harus dirinya sendiri atau user yang ia buat.

# ⏳ Siklus Masa Aktif Server

```text
 Dibuat ──► Aktif 30 hari ──► Peringatan (H-3, H-1) ──► Expired ──► Auto SUSPEND
                                                                      │
                                         Perpanjang (Admin) ◄─────────┤ ≤ 3 hari
                                                                      ▼
                                                           Tidak diperpanjang ──► Auto DELETE
```

- Peringatan dikirim ke notifikasi user (H-3 dan H-1)
- Perpanjang dari **Admin → Masa Aktif Server** (server yang disuspend karena expired otomatis aktif kembali)
- Durasi aktif dan masa tenggang bisa diubah di **Admin → Pengaturan Kazama**
- Diproses oleh scheduler tiap 5 menit (`kazama:expiry`)

# 💾 Sistem Backup

### Panel Backup (Admin ID 1)
- Buat backup baru (database MySQL + kunci enkripsi `.env`) dalam `.tar.gz`, siap migrasi antar VPS
- Unduh, hapus, **Upload & Restore** (dengan konfirmasi `RESTORE`)
- Auto-backup panel: setiap jam / harian / mingguan, jam dalam **WIB**
- Salinan otomatis ke **Telegram Bot** (maks. 49 MB) dan/atau disk cloud (S3, dll.)

### Auto-Backup per Server
Tersedia di semua server: **Settings → Backup Otomatis**
1. Toggle **default mati** (bulatan di kiri)
2. Klik untuk menyalakan (bulatan pindah ke kanan)
3. Atur frekuensi, jam (**WIB**), dan hari (untuk mingguan), lalu **Simpan**

# 🚀 Instalasi

### Persyaratan
| Komponen | Versi |
|---|---|
| Pterodactyl Panel | 1.11.x |
| PHP | 8.1+ |
| Node.js | 18+ (untuk build frontend) |
| Lainnya | `python3`, `yarn`, `mysqldump` & `mysql`, cron `schedule:run` aktif |

### Langkah
```bash
git clone https://github.com/kazamaofficial-git/kazama-theme-pterodactyl
cd kazama-theme-pterodactyl
bash install.sh /var/www/pterodactyl
```

Installer akan: backup file asli → salin theme → patch file inti → migrasi database → beri masa aktif server lama → build frontend → aktifkan kembali panel.

### Cron (wajib)
```bash
* * * * * php /var/www/pterodactyl/artisan schedule:run >> /dev/null 2>&1
```

### Uninstall / Rollback
```bash
bash uninstall.sh /var/www/pterodactyl /var/www/pterodactyl/storage/kazama-theme-backup-XXXXXXXX-XXXXXX
```

> ⚠️ **Disarankan mencoba di panel staging terlebih dahulu**, dan lakukan backup database sebelum memasang.

# 🔑 Konfigurasi Google OAuth

1. Buka **Google Cloud Console → APIs & Services → Credentials → Create OAuth client ID (Web application)**
2. Tambahkan **Authorized redirect URI**:
   ```text
   https://DOMAIN-PANEL-ANDA/auth/google/callback
   ```
3. Isi di `.env` panel:
   ```env
   KAZAMA_GOOGLE_CLIENT_ID=xxxxxxxx.apps.googleusercontent.com
   KAZAMA_GOOGLE_CLIENT_SECRET=xxxxxxxx
   ```
4. Jalankan `php artisan config:clear`

### Variabel `.env` lain
| Variabel | Fungsi | Default |
|---|---|---|
| `KAZAMA_CONTACT_TELEGRAM` | Kontak admin untuk beli server | `https://t.me/DhilzzKZ` |
| `KAZAMA_CONTACT_WHATSAPP` | Link WhatsApp admin | kosong |
| `KAZAMA_REGISTRATION` | Buka/tutup pendaftaran | `true` |
| `KAZAMA_BACKUP_DISK` | Disk Laravel untuk salinan cloud | kosong |
| `APP_LOCALE` | Bahasa panel | `id` |

# 🧰 Perintah Artisan

| Perintah | Fungsi |
|---|---|
| `php artisan kazama:expiry` | Cek masa aktif: peringatan, suspend, hapus |
| `php artisan kazama:auto-backup` | Jalankan auto-backup server yang jadwalnya tiba |
| `php artisan kazama:panel-backup` | Buat backup panel (`--auto` untuk mode jadwal) |
| `php artisan kazama:backfill --days=30` | Beri masa aktif pada server lama |
